What is a method signature? What is not part of it?	The name plus the parameter types.<br>Parameter names are not part of it. The return type is not part of it.	week2 methods
Do these overload, or fail to compile?<pre>static int pick(int x) { return x; }<br>static long pick(int x) { return x; }</pre>	They do not compile. Both have the signature <code>pick(int)</code>.<br>A different return type alone is not an overload.	week2 methods
When several methods could accept a call, in what order does Java choose?	1. Exact parameter types.<br>2. Widen a primitive (<code>int</code> to <code>long</code>).<br>3. Box (<code>int</code> to <code>Integer</code>). After boxing, the value may widen to a supertype such as <code>Object</code>.<br>4. Varargs.<br>Widening beats boxing. Boxing beats varargs.	week2 methods
<code>pick(int)</code>, <code>pick(long)</code>, and <code>pick(Integer)</code> all exist. What does <code>pick(1)</code> print?	<code>int</code>. The argument is an <code>int</code>, so the exact match wins.<br>The other two methods are legal overloads and are not used.	week2 methods
Only <code>pick(long)</code> and <code>pick(Integer)</code> exist. What does <code>pick(1)</code> print?	<code>long</code>.<br>Widening <code>int</code> to <code>long</code> is tried before boxing <code>int</code> to <code>Integer</code>.	week2 methods
Does an <code>int</code> argument match a <code>Long</code> parameter? Does it match <code>Object</code>?	It does not match <code>Long</code>. That would widen and then box, and a method call does not do both.<br>It can match <code>Object</code>: box to <code>Integer</code>, then widen to <code>Object</code>.	week2 methods
Does this compile?<pre>static int value(boolean flag) {<br>    if (flag) return 1;<br>}</pre>What is legal in a <code>void</code> method?	It does not compile. A non-<code>void</code> method must return a value on every path that can finish.<br>A <code>void</code> method may use a bare <code>return;</code>.	week2 methods
Where may a varargs parameter sit, and what is it inside the method? What does <code>m()</code> pass to <code>m(int... a)</code>?	It is the last parameter, and a method has only one.<br>Inside the method it is an array.<br><code>m()</code> passes an empty array, so <code>a.length</code> is <code>0</code>. It does not pass <code>null</code>. <code>m(1, 2)</code> passes an array of length 2.	week2 methods
Why do these not compile together?<pre>static void same(int[] nums) {}<br>static void same(int... nums) {}</pre>	<code>int...</code> and <code>int[]</code> are the same signature.<br>A parameter after the varargs also fails: <code>void bad(int... nums, int extra)</code>.	week2 methods
<code>add(int, int)</code> and <code>add(int...)</code> both exist. Which runs for <code>add(1, 2)</code>, and which for <code>add(1, 2, 3)</code>?	<code>add(1, 2)</code> uses <code>add(int, int)</code>. The exact match beats varargs.<br><code>add(1, 2, 3)</code> uses the varargs method. That array has length 3.	week2 methods
Why does <code>show(1, 2)</code> fail when the methods are <code>show(int, long)</code> and <code>show(long, int)</code>?	The call is ambiguous. Each method needs one widening, so neither is better.<br>A call that matches two methods equally does not compile.	week2 methods
What is the result of <code>pick(null)</code> when the methods are <code>pick(Integer)</code> and <code>pick(String)</code>?	The code does not compile. <code>null</code> matches both reference types equally.<br>No method runs, so nothing throws.	week2 methods
<code>reassign</code> does <code>s = &quot;changed&quot;</code> on a <code>String</code> parameter. <code>mutate</code> does <code>sb.append(&quot;!&quot;)</code> on a <code>StringBuilder</code>. Start from <code>&quot;Ada&quot;</code> and <code>&quot;cat&quot;</code>. What prints?	<code>Ada</code> then <code>cat!</code>.<br>Java copies each argument. Reassigning the parameter changes the copy. <code>append</code> changes the same builder the caller still holds.	week2 methods
<pre>void reassign(int[] a) { a = new int[] {9}; }<br>void mutate(int[] a) { a[0] = 9; }</pre>Start from <code>{1, 2}</code>, call <code>reassign</code>, print <code>nums[0]</code>, call <code>mutate</code>, print <code>nums[0]</code>. What prints?	<code>19</code>.<br><code>reassign</code> points its own copy at a new array, so the caller is still <code>{1, 2}</code>. <code>mutate</code> writes into the same array.	week2 methods
<pre>String s = &quot;animal&quot;;<br>s.substring(0, 3);<br>System.out.println(s);</pre>What prints? What changes if you write <code>s = s.substring(0, 3)</code>?	The first print is <code>animal</code>. A <code>String</code> cannot be changed. <code>substring</code> returns a new string, and this call does not assign it.<br>After the assignment, <code>s</code> is <code>ani</code>.	week2 text
<code>String a = &quot;hi&quot;; String b = &quot;hi&quot;; String c = new String(&quot;hi&quot;);</code> What are <code>a == b</code>, <code>a == c</code>, and <code>a.equals(c)</code>?	<code>true</code>, <code>false</code>, <code>true</code>.<br>The same literal shares one pooled object. <code>new String</code> is a different object. <code>==</code> compares references. <code>equals</code> compares characters.	week2 text
What is <code>&quot;animal&quot;.substring(1, 4)</code>? What about <code>substring(3, 3)</code> and <code>substring(6)</code> on that length-6 string?	<code>nim</code>, <code>&quot;&quot;</code>, and <code>&quot;&quot;</code>.<br>The end index is exclusive. A start equal to the length is the empty string. A start past the length, or a start after the end index, throws <code>StringIndexOutOfBoundsException</code>. <code>substring(7)</code> throws. <code>substring(3)</code> is <code>mal</code>.	week2 text
What do <code>&quot;animals&quot;.indexOf('a')</code>, <code>&quot;animals&quot;.indexOf(&quot;al&quot;)</code>, and <code>&quot;animals&quot;.indexOf('z')</code> return? What is <code>&quot;animal&quot;.indexOf('a', 1)</code>?	<code>0</code>, <code>4</code>, and <code>-1</code>.<br><code>indexOf</code> returns the first match, or <code>-1</code> when the character or string is missing.<br>The search from index 1 finds the second <code>a</code> at index 4.	week2 text
What is <code>&quot;hi&quot;.equals(null)</code>? What if the receiver is <code>null</code>?	<code>&quot;hi&quot;.equals(null)</code> is <code>false</code>.<br>Calling <code>equals</code> on a <code>null</code> reference throws <code>NullPointerException</code>.	week2 text
What is <code>&quot;  hi  &quot;.strip()</code>? How does <code>strip</code> differ from <code>trim</code>?	<code>&quot;hi&quot;</code>.<br><code>strip</code> also removes Unicode whitespace. <code>trim</code> only removes characters at or below U+0020.	week2 text
What are <code>&quot; &quot;.isEmpty()</code>, <code>&quot; &quot;.isBlank()</code>, and <code>&quot;&quot;.isBlank()</code>?	<code>false</code>, <code>true</code>, <code>true</code>.<br><code>isEmpty</code> is true only when the length is 0. <code>isBlank</code> is true for empty text or text that is only whitespace.	week2 text
What does <code>&quot;a&quot;.indent(1)</code> equal?	<code>&quot; a\n&quot;</code>.<br><code>indent</code> indents each line, turns line endings into <code>\n</code>, and the result ends with <code>\n</code>.	week2 text
What is <code>&quot;Hi %s&quot;.formatted(&quot;Java&quot;)</code>?	<code>Hi Java</code>.<br>This is the same idea as <code>String.format</code>.	week2 text
What is <code>&quot;cat&quot;.charAt(0)</code>? How do you ask for the length of a <code>String</code>, and how do you ask for the length of an array?	<code>'c'</code>. An index that does not exist throws <code>StringIndexOutOfBoundsException</code>.<br>A string uses the method <code>length()</code>. An array uses the field <code>length</code>, with no parentheses.	week2 text
Which of these compile?<pre>String a = &quot;&quot;&quot;cat&quot;&quot;&quot;;<br>String b = &quot;&quot;&quot;<br>        cat<br>        &quot;&quot;&quot;;</pre>When <code>cat</code> and the closing quotes start in the same column, what is <code>b</code>?	Only <code>b</code>. The opening <code>&quot;&quot;&quot;</code> must end its line, so a text block cannot sit on one line.<br>The closing <code>&quot;&quot;&quot;</code> sets the indent that is removed. Here the value is <code>cat\n</code>. Content farther right than the closing quotes keeps its extra spaces.	week2 text
Which <code>StringBuilder</code> methods change the buffer and return the same builder? Why does <code>sb.substring(0, 3).append(&quot;x&quot;)</code> fail?	<code>append</code>, <code>insert</code>, <code>delete</code>, <code>deleteCharAt</code>, <code>reverse</code>, and <code>replace</code> change the buffer and return it, so they can chain.<br><code>substring</code> returns a <code>String</code>. <code>String</code> has no <code>append</code>, so the chain does not compile. The builder itself is unchanged by that call.	week2 text
<code>var sb = new StringBuilder(&quot;hi&quot;);</code> What are <code>sb.equals(&quot;hi&quot;)</code> and <code>sb.toString().equals(&quot;hi&quot;)</code>?	<code>false</code> and <code>true</code>.<br><code>StringBuilder</code> does not override <code>equals</code>, so it uses reference equality. Compare the characters with <code>toString()</code>.	week2 text
A loop does <code>s += i</code> for <code>i</code> from 0 to 2, and another loop does <code>sb.append(i)</code>. Both end as <code>&quot;012&quot;</code>. What is the difference?	Each <code>+=</code> builds a new <code>String</code> and copies the characters so far.<br><code>StringBuilder.append</code> updates one buffer.<br><code>s.equals(sb.toString())</code> is <code>true</code>. The equal characters do not mean the same number of copies.	week2 text
Start from <code>&quot;abc&quot;</code>. What is left after <code>append(&quot;de&quot;).delete(1, 3).reverse()</code>?	<code>eda</code>.<br><code>&quot;abc&quot;</code> plus <code>&quot;de&quot;</code> is <code>abcde</code>. <code>delete(1, 3)</code> removes indexes 1 and 2, leaving <code>ade</code>. <code>reverse</code> leaves <code>eda</code>. The end index of <code>delete</code> is exclusive.	week2 text
What does <code>new int[3]</code> contain? What does <code>new String[2]</code> contain? Does <code>nums.length()</code> compile?	<code>0, 0, 0</code> and <code>null, null</code>.<br><code>length</code> is a field, so <code>nums.length()</code> does not compile. A <code>String</code> uses <code>length()</code>.	week2 arrays
Which indexes of an array are legal? What does <code>new int[2]</code> do at <code>nums[0]</code> and then at <code>nums[2]</code>?	Indexes <code>0</code> through <code>length - 1</code>.<br><code>nums[0]</code> prints <code>0</code>. <code>nums[2]</code> throws <code>ArrayIndexOutOfBoundsException</code>.	week2 arrays
Which of these compile?<pre>int[] a = {1, 2, 3};<br>int[] c;<br>c = {1, 2};</pre>	The declaration compiles. The later assignment does not.<br>The brace form without <code>new</code> is allowed only in the declaration. Write <code>c = new int[] {1, 2};</code>.	week2 arrays
What is the default of an array field? What does reading <code>null.length</code> do?	An array field defaults to <code>null</code>.<br>Reading <code>null.length</code> throws <code>NullPointerException</code>.	week2 arrays
What does <code>Arrays.binarySearch</code> require, and what does a missing value return?	The array must be sorted. <code>Arrays.sort</code> sorts in place. On an unsorted array the result is undefined, not a particular index.<br>A present value returns its index. A missing value returns <code>-(insertion point) - 1</code>. The insertion point is where the value would go to keep the array sorted.	week2 arrays
On <code>{1, 3, 5, 7}</code>, what are <code>binarySearch</code> of <code>5</code>, <code>4</code>, and <code>0</code>?	<code>2</code>, <code>-3</code>, and <code>-1</code>.<br><code>5</code> is at index 2. <code>4</code> would be inserted at index 2, and <code>-(2) - 1</code> is <code>-3</code>. <code>0</code> would be inserted at index 0.<br>For a negative result, the insertion point is <code>-result - 1</code>.	week2 arrays
<code>int[] nums = {3, 1, 2};</code> After <code>Arrays.sort(nums)</code>, what is <code>Arrays.binarySearch(nums, 2)</code>?	<code>1</code>.<br>The sorted array is <code>{1, 2, 3}</code>, and <code>2</code> is at index 1.	week2 arrays
What do <code>Arrays.equals</code>, <code>==</code>, <code>Arrays.mismatch</code>, and <code>Arrays.compare</code> tell you about two arrays?	<code>Arrays.equals</code> compares elements one level deep. <code>==</code> compares the two array references.<br><code>mismatch</code> returns the first index that differs, or <code>-1</code> when the arrays match. <code>{1, 2, 3}</code> against <code>{1, 2, 4}</code> is <code>2</code>, and an array against itself is <code>-1</code>, so the print is <code>2-1</code>.<br><code>compare</code> returns a negative number, zero, or a positive number, in the same style as <code>compareTo</code>.	week2 arrays
<pre>Object[] objects = new String[1];<br>objects[0] = 1;</pre>What happens?	It compiles, then throws <code>ArrayStoreException</code>.<br>The variable type is <code>Object[]</code>, so the assignment is legal to the compiler. The array's runtime type is <code>String[]</code>, so it rejects the <code>Integer</code>.	week2 arrays
What are <code>jagged.length</code>, <code>jagged[0].length</code>, and <code>jagged[1].length</code> for <code>int[][] jagged = {{1, 2}, {3}}</code>? What about <code>new int[2][]</code>?	<code>2</code>, <code>2</code>, and <code>1</code>. The outer array has two slots. The inner arrays may have different lengths.<br><code>new int[2][]</code> creates two slots and leaves them <code>null</code>. <code>rows[0] == null</code> is true. <code>rows[1].length</code> throws <code>NullPointerException</code>. Assign an inner array before using <code>rows[0][0]</code>.	week2 arrays
