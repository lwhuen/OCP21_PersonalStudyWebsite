Primitive

One of eight types: byte 8-bit, short 16, int 32, long 64, float 32, double 64, char 16-bit unsigned, boolean.

−128 to 127. byte b = 128 does not compile.

char

An unsigned number from 0 to 65,535. A negative literal such as char c = -1 does not compile. A cast such as (char) -1 does.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Field default

A field that is not assigned starts as 0, false, '\u0000', or null. Locals do not get these defaults.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Literal

A value written in source. A whole number is an int unless it ends in L. 1.0 is a double. A float literal ends in f.

A leading 0 means base 8. 011 is 9. 018 does not compile, because 8 is not an octal digit.

Allowed only between digits. 1_000 compiles. 10_L, 0x_11, and 1_000_ do not.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

var

One local variable with an initializer the compiler can type. Not a field, a parameter, or a return type. var x; and var y = null do not compile. var n = (String) null does, because the cast supplies the type.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Scope

The block where a name can be used. An inner block cannot declare int x when the outer block already has int x. After the inner block ends, the name may be declared again.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Wrapper

An object for a primitive: Integer, Long, Double, and the others. On Java 21, new Integer(1) does not compile. Use Integer n = 1 or Integer.valueOf(1).

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Boxing

Wrapping a primitive in its wrapper. Integer n = 1 boxes.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Unboxing

Taking the primitive out of a wrapper. int value = n unboxes. Unboxing null throws NullPointerException.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Integer cache

Integer reuses one object for each value from −128 to 127. == on two wrappers compares references, so 127 == 127 is true and 128 == 128 is false. equals compares the number. Byte, Short, and Long use the same cache. Character caches 0 to 127. Float and Double do not cache.

詞彙卡 · Wednesday — primitives, literals, var , wrappers

Wrapper compared with a primitive

Integer == int unboxes the wrapper, so the cache does not matter. Integer a = 200; int b = 200; a == b is true.

詞彙卡 · Friday — operators

Precedence

Which operator runs first. Postfix ++, then *, then +, then &&, then \|\|, then ?:. ?: and assignment associate right to left. Most others associate left to right.

詞彙卡 · Friday — operators

Numeric promotion

byte, short, and char arithmetic produces an int. A constant expression whose result fits may still be assigned: byte d = 1 + 2 compiles, byte c = a + b does not.

詞彙卡 · Friday — operators

Compound assignment

+=, -=, *=, and the rest. The operation includes a hidden cast back to the left-hand type, so b += 1 compiles when b = b + 1 does not. n *= 2 + 3 means n = n * (2 + 3).

詞彙卡 · Friday — operators

Postfix and prefix

x++ contributes the current value, then adds 1. ++x adds 1, then contributes the new value. After int x = 1; int y = x++ + ++x, x is 3 and y is 4.

詞彙卡 · Friday — operators

Short-circuit

&& and \|\| skip the right side when the result is already known. & and \| on a boolean always evaluate both sides.

詞彙卡 · Friday — operators

Integer division

5 / 2 is 2. Truncation is toward zero. The sign of % follows the dividend, so -5 % 2 is -1. An int divided by zero throws ArithmeticException. 1.0 / 0.0 is Infinity.

詞彙卡 · Friday — operators

Cast

An explicit conversion, such as (int) 5.0. Casting a double toward zero drops the fraction: (int) 9.9 is 9 and (int) -9.9 is -9. (boolean) 1 does not compile. A boolean cannot be cast to or from a number.

詞彙卡 · Friday — operators

Shift

An int shift distance is taken mod 32, so 1 << 32 is 1 << 0, which is 1. 1 << 31 is Integer.MIN_VALUE.

詞彙卡 · Friday — operators

Ternary

condition ? a : b. It associates to the right. Both branches share one type. flag ? 1 : 2.0 has type double.

詞彙卡 · Friday — operators

Toward negative infinity. floor(-1.1) is -2.0. Returns double.

Unreachable

詞彙卡 · Saturday and Sunday — Math and flow

Single statement

A local-variable declaration cannot be the only statement of an if or a loop. Use a block.

Classic switch

The selector may be byte, short, char, int, their wrappers, String, or an enum. Not long, float, double, or boolean. A case label is a compile-time constant. Duplicate labels do not compile.

詞彙卡 · Saturday and Sunday — Math and flow

Fall-through

In a colon switch, a case without break continues into the next case. default may sit anywhere. No match and no default means a switch statement does nothing.

詞彙卡 · Saturday and Sunday — Math and flow

Arrow switch

Cases use -> and do not fall through. They do not use break. Mixing -> and : in one switch does not compile.

詞彙卡 · Saturday and Sunday — Math and flow

Switch expression

Produces a value. On an int it must cover every remaining value, so it needs a default or enough cases. A block produces its value with yield. break 10 is not Java.

null selector

A switch on a null String throws NullPointerException before any case or default runs.

The body runs at least once. The semicolon after while (...) is required. int i = 0; do { print i; } while (i++ < 2); prints 012.

詞彙卡 · Saturday and Sunday — Math and flow

break

Leaves the nearest loop or switch. break with a label leaves the named enclosing loop or switch.

詞彙卡 · Saturday and Sunday — Math and flow

continue

Starts the next iteration of the nearest loop. continue with a label must name a loop.

詞彙卡 · Saturday and Sunday — Math and flow

Enhanced for

for (int n : nums) gives n a separate copy. Assigning to n does not write into the array. A null array throws NullPointerException.

詞彙卡 · Monday — methods and overloading

Signature

The method name plus the parameter types. Parameter names are not part of it. The return type is not part of it.

詞彙卡 · Monday — methods and overloading

Overload

Two methods with the same name and different parameter lists. A different return type alone is not an overload. It does not compile.

詞彙卡 · Monday — methods and overloading

Return path

A non-void method must return a value on every path that can finish. A void method may use a bare return;.

詞彙卡 · Monday — methods and overloading

Overload resolution

The order Java picks a method: exact match, then primitive widening, then boxing, then varargs. Widening beats boxing. Boxing beats varargs.

Widening

A primitive becomes a wider primitive, such as int to long. An int argument does not match a Long parameter, because that would widen and then box.

int can box to Integer, and that Integer can then widen to Object. Widening a primitive is tried before this boxing.

A last parameter written int... nums. A method has only one. Inside the method it is an array. A call with no extra arguments passes an empty array, not null.

Java copies each argument into the parameter. Reassigning the parameter changes the copy. Mutating the object the copy points at changes the object the caller still holds.

isEmpty

A changeable buffer. append, insert, delete, deleteCharAt, reverse, and replace change that buffer and return it, so they can chain.

The end index is exclusive. "abcde" after delete(1, 3) is ade.

詞彙卡 · Saturday — threads

A lightweight thread. Start one with Thread.ofVirtual().start or Thread.startVirtualThread. Do not build a pool of them by hand.

詞彙卡 · Saturday — threads

ReentrantLock

A map that concurrent tasks may update. A null key or a null value throws NullPointerException.

A parallel stream of a collection. An associative sum matches the sequential sum. forEach may run in any order.
