Start from <code>[1, 2, 3]</code>. What is left after <code>remove(1)</code>, then after <code>remove(Integer.valueOf(1))</code>?	<code>[1, 3]</code>, then <code>[3]</code>.<br><code>remove(int)</code> deletes an index. On a <code>List&lt;Integer&gt;</code>, the literal <code>1</code> is an index. <code>Integer.valueOf</code> selects <code>remove(Object)</code> and deletes the value.	week6 list
What does <code>List.of(1, 2).add(3)</code> do? What can <code>Arrays.asList</code> do?	<code>add</code> throws <code>UnsupportedOperationException</code>. <code>List.of</code> also rejects null.<br><code>Arrays.asList</code> allows <code>set</code> and refuses <code>add</code> and <code>remove</code>.	week6 list
For <code>ArrayList</code>, <code>HashSet</code>, <code>TreeSet</code>, <code>HashMap</code>, and <code>TreeMap</code>: which are ordered, and which allow null?	<code>ArrayList</code> keeps insertion order and allows null elements.<br><code>HashSet</code> and <code>HashMap</code> have no order you can rely on. A set allows one null. A map allows one null key and null values.<br><code>TreeSet</code> and <code>TreeMap</code> are sorted. Natural order rejects a null element or a null key with <code>NullPointerException</code>.	week6 sets
A <code>TreeSet</code> is built from <code>b, a, c, a</code>. What does it print? A <code>HashMap</code> <code>put</code>s key <code>a</code> as <code>2</code> and then as <code>9</code>. What does <code>get(&quot;a&quot;)</code> return?	The tree prints <code>[a, b, c]</code>. Duplicates are dropped and the elements are sorted.<br><code>get</code> returns <code>9</code>. The second <code>put</code> replaces the value for that key.	week6 sets
A <code>HashMap</code> already has a null key. What does a second <code>put(null, 1)</code> do?	It replaces the value for the one null key.<br>It does not throw, and it does not store a second null key.	week6 sets
Push <code>a</code> then <code>b</code> on a stack. Offer <code>a</code> then <code>b</code> on a queue. What are the first <code>pop</code> and the first <code>poll</code>?	The first pop is <code>b</code>. A stack removes the last push.<br>The first poll is <code>a</code>. A queue removes the first offer.<br><code>poll</code> on an empty deque returns <code>null</code>. <code>pop</code> on an empty deque throws <code>NoSuchElementException</code>.	week6 sort
<code>addLast(&quot;a&quot;)</code> then <code>addFirst(&quot;b&quot;)</code>. What are <code>getFirst</code>, <code>getLast</code>, and <code>reversed()</code>?	<code>b</code>, <code>a</code>, and <code>[a, b]</code>.<br><code>reversed</code> is a reverse-ordered view. <code>List</code>, <code>Deque</code>, <code>SortedSet</code>, and <code>LinkedHashSet</code> are sequenced. <code>HashSet</code> is not. <code>ArrayDeque</code> rejects null.	week6 sort
<code>Ada</code>, <code>Bea</code>, and <code>Cy</code> are sorted by length, then by natural order. What is the list?	<code>[Cy, Ada, Bea]</code>.<br><code>comparing</code> uses the first key. <code>thenComparing</code> breaks ties. <code>Cy</code> has length 2. The other two have length 3, and <code>Ada</code> precedes <code>Bea</code>.	week6 sort
<code>compareTo</code> returns a negative number. Where does this object sort?	Before the argument.<br>Zero means the same position in the order. Zero does not by itself prove <code>equals</code>.	week6 sort
<code>List&lt;? extends Number&gt; nums = new ArrayList&lt;Integer&gt;()</code>. Can you <code>add(1)</code>? What does <code>get</code> return?	You cannot add an <code>Integer</code>. The list might be a <code>List&lt;Double&gt;</code>.<br><code>get</code> returns a <code>Number</code>. <code>null</code> is the reference you may add.	week6 generics
<code>List&lt;? super Integer&gt; sink = new ArrayList&lt;Number&gt;()</code>. Can you <code>add(1)</code>? What is the type of <code>get</code>?	Yes, you can add an <code>Integer</code>.<br><code>get</code> returns <code>Object</code>, because the list might be a <code>List&lt;Object&gt;</code> or a <code>List&lt;Number&gt;</code>.	week6 generics
Do <code>show(List&lt;String&gt;)</code> and <code>show(List&lt;Integer&gt;)</code> compile in one class?	No. Erasure makes both methods <code>show(List)</code>.<br>Type arguments are not part of the runtime signature.	week6 generics
What can you add to a <code>List&lt;?&gt;</code>? Which of these accept a <code>List&lt;String&gt;</code>: <code>List&lt;Object&gt;</code>, <code>List&lt;? extends CharSequence&gt;</code>, <code>List&lt;CharSequence&gt;</code>?	Only <code>null</code>. <code>get</code> returns <code>Object</code>.<br>Only <code>List&lt;? extends CharSequence&gt;</code> accepts a <code>List&lt;String&gt;</code>. Generics are invariant, so the other two assignments do not compile.	week6 generics
A <code>HashMap.get</code> returns <code>null</code>. How do you tell a missing key from a stored null value?	Call <code>containsKey</code>.<br><code>get</code> returns <code>null</code> in both cases.	week6 sets
Does a <code>List</code> keep duplicates? Does a <code>Set</code>?	A <code>List</code> keeps duplicates and insertion order.<br>A <code>Set</code> keeps one element for each <code>equals</code> match. <code>HashSet</code> does not promise an order. <code>TreeSet</code> sorts.	week6 list
