Name the 8 Java primitives and the size of each.	byte 8-bit, short 16, int 32, long 64, float 32, double 64, char 16-bit unsigned, boolean.<br>byte is −128 to 127. char is 0 to 65,535.	week1 primitives
What are the field defaults for <code>int</code>, <code>boolean</code>, <code>char</code>, and a reference such as <code>String</code>?	<code>0</code>, <code>false</code>, <code>'\u0000'</code>, and <code>null</code>.<br>Local variables have no default. Reading one before it is assigned does not compile.	week1 primitives
Does <code>float f = 1.0;</code> compile? What about <code>float f = 1;</code>?	<code>1.0</code> is a double, so the first line does not compile. Write <code>1.0f</code> or cast.<br><code>float f = 1;</code> compiles: an int widens to float.	week1 primitives
Does <code>long x = 3000000000;</code> compile?	No. A whole-number literal is an <code>int</code>, and that value does not fit in an int.<br>Write <code>3000000000L</code>.	week1 primitives
Does <code>byte b = 128;</code> compile? Does <code>char c = -1;</code>?	Neither compiles. A byte only goes to 127. A char cannot be negative.<br><code>byte b = 127;</code> and <code>char c = 65;</code> compile. A cast such as <code>(char) -1</code> compiles.	week1 primitives
What is <code>int n = 011;</code>? Why does <code>int n = 018;</code> fail?	<code>011</code> is octal and equals 9. A leading zero means octal.<br>8 is not an octal digit, so <code>018</code> does not compile.	week1 primitives
Which of these literals compile: <code>1_000</code>, <code>10_L</code>, <code>0x_11</code>, <code>1_000_</code>?	Only <code>1_000</code>. An underscore must sit between digits.<br>Not at an end, not next to the <code>L</code>/<code>F</code> suffix, and not immediately after <code>0x</code>.	week1 primitives
Which compile? <code>var x;</code> <code>var y = null;</code> <code>var z = {1, 2};</code> <code>var e = new int[]{1, 2};</code>	Only <code>var e = new int[]{1, 2};</code>.<br><code>var</code> is one local variable with an initializer the compiler can type. <code>var n = (String) null;</code> compiles because the cast supplies the type.<br><code>var</code> cannot be a field, a parameter, or a return type.	week1 primitives
Can an inner block declare <code>int x</code> when the enclosing block already has <code>int x</code>?	No. The name is already in scope.<br>After the inner block ends, <code>int x</code> may be declared again.	week1 primitives
Does <code>new Integer(1)</code> compile on Java 21?	No. The wrapper constructors were removed.<br>Use <code>Integer n = 1;</code> or <code>Integer.valueOf(1)</code>.	week1 wrappers
What happens here?<pre>Integer n = null;
int value = n;</pre>	It compiles. Unboxing <code>null</code> throws <code>NullPointerException</code>.	week1 wrappers
<code>Integer a = 127, b = 127;</code> and <code>Integer c = 128, d = 128;</code>. What are <code>a == b</code>, <code>c == d</code>, and <code>c.equals(d)</code>?	<code>true</code>, <code>false</code>, <code>true</code>.<br><code>==</code> on two wrappers compares references. <code>Integer</code> caches −128 to 127, so 127 is one shared object and 128 is not.<br><code>equals</code> compares the number. <code>Byte</code>, <code>Short</code>, and <code>Long</code> use the same cache. <code>Character</code> caches 0 to 127. <code>Float</code> and <code>Double</code> do not cache.	week1 wrappers
<code>Integer a = 200; int b = 200;</code> What is <code>a == b</code>?	<code>true</code>. Comparing a wrapper to a primitive unboxes the wrapper, so the cache does not matter.<br>Two <code>Integer</code> objects of 200 compared with <code>==</code> would be <code>false</code>.	week1 wrappers
Which of these are valid <code>main</code> entry points?<pre>public static void main(String[] args)
static public void main(String args[])
public static void main(String... args)</pre>	All three. <code>public</code> and <code>static</code> may be swapped. The parameter is a <code>String</code> array or <code>String</code> varargs.<br>The name is <code>main</code> and the return type is <code>void</code>.	week1 primitives
What does <code>1 + 2 + "3" + 4 + 5</code> print?	<code>3345</code>. <code>+</code> is left to right. <code>1 + 2</code> is 3, then the string turns the rest into concatenation.	week1 operators
<code>byte a = 1; byte b = 2;</code> Does <code>byte c = a + b;</code> compile? Does <code>byte d = 1 + 2;</code>?	<code>c</code> does not: <code>byte</code>, <code>short</code>, and <code>char</code> arithmetic produces an <code>int</code>.<br><code>d</code> does: <code>1 + 2</code> is a constant whose result fits in a byte. <code>byte e = (byte) (a + b);</code> also compiles.	week1 operators
For <code>byte b = 1;</code>, why does <code>b += 1;</code> compile when <code>b = b + 1;</code> does not?	A compound assignment includes a hidden cast: <code>b = (byte) (b + 1);</code>.<br>The right-hand side is one expression, so <code>n *= 2 + 3</code> means <code>n = n * (2 + 3)</code>.	week1 operators
<code>int x = 1; int y = x++ + ++x;</code> What are <code>x</code> and <code>y</code>?	<code>x</code> is 3 and <code>y</code> is 4.<br>Postfix contributes 1, then <code>x</code> is 2. Prefix raises <code>x</code> to 3 and contributes 3.	week1 operators
Start with <code>int x = 0;</code>. What is <code>x</code> after <code>false &amp;&amp; ++x == 1</code>, then after <code>false &amp; ++x == 1</code>?	After <code>&amp;&amp;</code>, <code>x</code> is still 0. <code>&amp;&amp;</code> and <code>||</code> skip the right side when the result is already known.<br>After <code>&amp;</code>, <code>x</code> is 1. <code>&amp;</code> and <code>|</code> on a boolean always evaluate both sides.	week1 operators
What are <code>5 / 2</code> and <code>-5 % 2</code>?	<code>2</code> and <code>-1</code>.<br>Integer division truncates toward zero. The sign of <code>%</code> follows the dividend.<br>An int divided by zero throws <code>ArithmeticException</code>. <code>1.0 / 0.0</code> is <code>Infinity</code>.	week1 operators
What is <code>1 &lt;&lt; 32</code> when the left side is an int?	<code>1</code>. An int shift distance is taken mod 32, so this is <code>1 &lt;&lt; 0</code>.<br><code>1 &lt;&lt; 31</code> is <code>Integer.MIN_VALUE</code>.	week1 operators
What do <code>Math.round(2.5)</code> and <code>Math.round(-1.5)</code> return, and what is the type of <code>Math.round(double)</code>?	<code>3</code> and <code>-1</code>. A tie rounds toward positive infinity.<br><code>Math.round(double)</code> returns <code>long</code>, so <code>int i = Math.round(2.5);</code> does not compile. <code>Math.round(float)</code> returns <code>int</code>.	week1 math
What are <code>Math.floor(-1.1)</code> and <code>Math.ceil(-1.1)</code>, and what type do they return?	<code>floor</code> is <code>-2.0</code> (toward negative infinity). <code>ceil</code> is <code>-1.0</code> (toward positive infinity).<br>Both return <code>double</code>.	week1 math
What does <code>Math.abs(Integer.MIN_VALUE)</code> return?	It returns <code>Integer.MIN_VALUE</code>, which is still negative.<br>The positive value does not fit in an int. The same trap exists for <code>Long.MIN_VALUE</code>.	week1 math
Does <code>(boolean) 1</code> compile?	No. A boolean cannot be cast to or from a number.	week1 operators
In <code>x &gt; 5 ? y &gt; 15 ? 1 : 2 : 3</code>, with <code>x = 10</code> and <code>y = 20</code>, what is the result?	<code>1</code>. <code>?:</code> associates to the right, so this is <code>x &gt; 5 ? (y &gt; 15 ? 1 : 2) : 3</code>.<br>Both branches of a ternary must share one type. <code>flag ? 1 : 2.0</code> has type double.	week1 operators
What does <code>if (ready = true)</code> do when <code>ready</code> is a boolean? What about <code>if (n = 5)</code> when <code>n</code> is an int?	The boolean version assigns <code>true</code> and then tests that value, so the body runs.<br><code>if (n = 5)</code> does not compile. <code>if</code> needs a boolean, and the assignment’s value is an int.	week1 flow
Which <code>if</code> does an <code>else</code> belong to?	The nearest <code>if</code>.<br>An outer <code>if (false)</code> means the inner <code>if</code>/<code>else</code> never runs.	week1 flow
Does <code>while (false) { }</code> compile? Does <code>if (false) { }</code>?	<code>while (false)</code> does not compile: the body is unreachable.<br><code>if (false)</code> does compile, and the lines after the <code>if</code> still run. This exception is only for <code>if</code>.	week1 flow
Does <code>if (true) int x = 1;</code> compile? What about the same declaration as the only statement of a <code>for</code>?	Neither compiles. A local-variable declaration cannot be the single statement of an <code>if</code> or a loop. Use a block.	week1 flow
Which types can a classic <code>switch</code> selector have?	<code>byte</code>, <code>short</code>, <code>char</code>, <code>int</code>, their wrappers, <code>String</code>, and an enum.<br>Not <code>long</code>, <code>float</code>, <code>double</code>, or <code>boolean</code>. A case label must be a compile-time constant. Duplicate labels do not compile.	week1 flow
A colon <code>switch</code> matches case 1, and case 1 has no <code>break</code> before case 2. What runs?	Case 1 and then case 2, until a <code>break</code> or the end of the switch. That is fall-through.<br><code>default</code> may sit anywhere. No match and no <code>default</code> means a switch statement does nothing.	week1 flow
Do arrow <code>switch</code> cases fall through? Can one switch mix <code>-&gt;</code> and <code>:</code>?	Arrow cases do not fall through, so they do not use <code>break</code>.<br>Mixing <code>-&gt;</code> and <code>:</code> in one switch does not compile.	week1 flow
Does this compile?<pre>int result = switch (n) {
    case 1 -&gt; 10;
    case 2 -&gt; 20;
};</pre>	No. A <code>switch</code> expression on an int must cover every remaining value, so it needs a <code>default</code> (or enough cases).<br>The same cases in a switch statement would compile.	week1 flow
How does a <code>{ }</code> block produce the value of a switch expression?	With <code>yield</code>. Example: <code>case 1 -&gt; { yield 10; }</code>.<br><code>yield</code> belongs to a switch expression. <code>break 10;</code> is not Java.	week1 flow
What happens if the selector of a <code>switch</code> on <code>String</code> is <code>null</code>?	<code>NullPointerException</code>, before any case or <code>default</code> runs.	week1 flow
<code>int i = 0; do { print i; } while (i++ &lt; 2);</code> What is printed?	<code>012</code>. The body runs, then the condition uses the current <code>i</code> and increments it.<br>A <code>do</code>/<code>while</code> runs at least once. The semicolon after <code>while (...)</code> is required.	week1 flow
What is the difference between <code>break</code>, <code>continue</code>, and <code>break outer</code>?	<code>break</code> leaves the nearest loop or switch.<br><code>continue</code> starts the next iteration of the nearest loop.<br>A label names an enclosing loop. <code>break</code> with a label may also name an enclosing switch. <code>continue</code> with a label must name a loop.	week1 flow
<pre>int[] nums = {1, 2, 3};
for (int n : nums) { n = 9; }</pre>What is <code>nums[0]</code> afterwards?	<code>1</code>. The enhanced-for variable is a separate <code>int</code>. Assigning to it does not write into the array.<br>A <code>null</code> array in an enhanced for throws <code>NullPointerException</code>.	week1 flow
Put these in the order Java evaluates them: <code>+</code>, <code>*</code>, <code>&amp;&amp;</code>, <code>||</code>, postfix <code>++</code>, <code>?:</code>.	Postfix <code>++</code>, then <code>*</code>, then <code>+</code>, then <code>&amp;&amp;</code>, then <code>||</code>, then <code>?:</code>.<br><code>?:</code> and assignment associate right to left. Most other operators associate left to right.	week1 operators
