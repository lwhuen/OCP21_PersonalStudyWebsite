A lambda reads local <code>n</code>, and the method assigns <code>n</code> again after the lambda. Does it compile?	No. A local used by a lambda must be final or effectively final.<br>A field does not have this limit. The lambda reads the field when it runs.	week7 lambda
Which lambda is a <code>Supplier&lt;String&gt;</code>: <code>s -&gt; &quot;ok&quot;</code>, <code>() -&gt; &quot;ok&quot;</code>, or <code>() -&gt; {}</code>?	<code>() -&gt; &quot;ok&quot;</code>. <code>get</code> takes no arguments and returns a value.<br><code>() -&gt; {}</code> returns nothing, so it is a <code>Runnable</code>.	week7 lambda
Does <code>s -&gt; { s.length(); }</code> compile as a <code>Function&lt;String, Integer&gt;</code>?	No. A brace body that produces a value needs <code>return</code>.<br><code>s -&gt; s.length()</code> is the expression form. It has no <code>return</code> and no semicolon.	week7 lambda
Name the four method-reference forms with one example each.	Static: <code>Integer::parseInt</code>.<br>Bound: <code>word::length</code>, where <code>word</code> is already chosen.<br>Unbound: <code>String::length</code>. The instance arrives as the argument.<br>Constructor: <code>ArrayList::new</code>.	week7 lambda
<code>String word = &quot;hi&quot;; Supplier&lt;Integer&gt; len = word::length;</code> What is <code>len.get()</code>? What is <code>Integer::parseInt</code> applied to <code>&quot;10&quot;</code>?	<code>2</code> and <code>10</code>.<br>The first reference is bound to <code>word</code>. The second is a static method reference.	week7 lambda
What are the abstract methods of <code>Supplier</code>, <code>Consumer</code>, <code>Predicate</code>, <code>Function</code>, and <code>UnaryOperator</code>?	<code>T get()</code>, <code>void accept(T)</code>, <code>boolean test(T)</code>, <code>R apply(T)</code>, and <code>T apply(T)</code>.<br><code>UnaryOperator&lt;T&gt;</code> is a function whose input and output types match.	week7 lambda
<code>Predicate&lt;String&gt; p = String::isEmpty</code>. What is <code>p.test(&quot;&quot;)</code>? What interface is <code>n -&gt; n &gt; 0</code> for a primitive <code>int</code>?	<code>true</code>. <code>String::isEmpty</code> is an unbound reference.<br>The primitive test is an <code>IntPredicate</code>. <code>ToIntFunction&lt;String&gt;</code> is <code>String::length</code> when the result must be a primitive <code>int</code>. <code>IntFunction&lt;String&gt;</code> goes from an <code>int</code> to a <code>String</code>.	week7 lambda
<code>Supplier&lt;List&lt;String&gt;&gt; lists = ArrayList::new</code>. What is <code>lists.get().size()</code>?	<code>0</code>.<br>The reference calls the empty constructor.	week7 lambda
A value is present. Does <code>orElse(mark())</code> call <code>mark</code>? Does <code>orElseGet(Opts::mark)</code>?	<code>orElse</code> calls <code>mark</code> even though a value is present.<br><code>orElseGet</code> calls the supplier only when the optional is empty.	week7 optional
What do <code>Optional.of(null)</code> and <code>Optional.ofNullable(null)</code> do? What does <code>Optional.empty().orElseThrow()</code> throw?	<code>of(null)</code> throws <code>NullPointerException</code>. <code>ofNullable(null)</code> is empty.<br><code>orElseThrow()</code> throws <code>NoSuchElementException</code>.	week7 optional
What is <code>Optional.empty().map(String::length)</code>? What does <code>Optional.of(&quot;hi&quot;).flatMap(s -&gt; Optional.of(s.length()))</code> print?	<code>Optional.empty</code>. <code>map</code> does not call the function when the optional is empty.<br>The <code>flatMap</code> prints <code>Optional[2]</code>. <code>flatMap</code> unwraps one level instead of nesting optionals.	week7 optional
<code>List.of(1, 2, 2, 3)</code> is filtered to values <code>&gt; 1</code>, then <code>distinct</code>, then multiplied by 10. What is the list?	<code>[20, 30]</code>.<br><code>filter</code> keeps <code>2, 2, 3</code>. <code>distinct</code> keeps <code>2, 3</code>.	week7 streams
What is <code>Stream.of(List.of(1, 2), List.of(3)).flatMap(List::stream).toList()</code>?	<code>[1, 2, 3]</code>.<br><code>flatMap</code> joins the inner streams. <code>map</code> would have left a stream of lists.	week7 streams
What is <code>Stream.of(3, 1, 2).sorted().limit(2).toList()</code>? What does <code>peek</code> print if no terminal operation runs?	<code>[1, 2]</code>.<br><code>peek</code> is intermediate. Without a terminal operation the pipeline does not run, so it prints nothing.	week7 streams
<code>Stream.of(&quot;a&quot;).count()</code> has already run. What does a second <code>count</code> on that stream do? What does <code>Stream.toList().add</code> do?	The second terminal operation throws <code>IllegalStateException</code>. A stream is consumed once.<br><code>toList()</code> returns a list that refuses <code>add</code>, so <code>add</code> throws <code>UnsupportedOperationException</code>.	week7 streams
<code>&quot;a&quot;, &quot;bb&quot;, &quot;a&quot;</code> grouped by length. What is under key <code>1</code>? With <code>counting()</code>, what is the value for key <code>2</code>?	Key <code>1</code> has <code>[a, a]</code>. Key <code>2</code> has <code>[bb]</code>.<br>With <code>counting()</code>, key <code>2</code> has the <code>Long</code> value <code>1</code>, and key <code>1</code> has <code>2</code>.	week7 streams
<code>&quot;a&quot;, &quot;bb&quot;, &quot;ccc&quot;</code> partitioned by <code>length &gt; 1</code>. What is under <code>false</code>? What does <code>IntStream.of(1, 2, 3).average()</code> return?	<code>false</code> has <code>[a]</code>. <code>true</code> has <code>[bb, ccc]</code>. <code>partitioningBy</code> always creates both keys.<br><code>average</code> returns <code>OptionalDouble[2.0]</code>, not a plain <code>double</code>.	week7 streams
What is <code>IntStream.range(1, 4).sum()</code>? What does <code>Stream.of(&quot;b&quot;, &quot;a&quot;).sorted().findFirst()</code> return?	The sum is <code>6</code>. <code>range</code> excludes the end, so the values are <code>1, 2, 3</code>. <code>rangeClosed(1, 4)</code> includes <code>4</code>.<br><code>findFirst</code> returns <code>Optional[a]</code>. An empty stream returns an empty optional. It does not throw.	week7 streams
What is <code>Stream.of(1, 2, 3).reduce(0, Integer::sum)</code>? What is <code>Stream.of(&quot;a&quot;, &quot;b&quot;, &quot;a&quot;).distinct().toList()</code>?	The sum is <code>6</code>.<br>The distinct list is <code>[a, b]</code>. An ordered stream keeps the first time each element appears.	week7 streams
What is <code>Stream.of(&quot;a&quot;, &quot;b&quot;, &quot;c&quot;).skip(1).limit(1).toList()</code>? What is <code>Collectors.joining(&quot;,&quot;)</code> of <code>a</code> and <code>b</code>?	<code>[b]</code>.<br>Joining with a comma produces <code>a,b</code>.	week7 streams
What do <code>anyMatch(n -&gt; n &gt; 2)</code> on <code>1, 2, 3</code>, <code>allMatch(n -&gt; n &gt; 0)</code> on <code>1, 2</code>, and <code>noneMatch(n -&gt; n &lt; 0)</code> on <code>1, 2</code> return?	All three return <code>true</code>.<br><code>anyMatch</code> stops when one element passes. <code>allMatch</code> requires every element. <code>noneMatch</code> requires every element to fail the test.	week7 streams
