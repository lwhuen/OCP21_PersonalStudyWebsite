Which pair moves bytes, and which pair moves characters?	<code>InputStream</code> and <code>OutputStream</code> move bytes.<br><code>Reader</code> and <code>Writer</code> move characters. <code>InputStreamReader</code> is the bridge. Close the outermost wrapper.	week8 io
On Windows, what do <code>resolve(&quot;extra.txt&quot;)</code> and <code>resolve</code> of <code>C:\temp\x.txt</code> do to <code>docs\notes\week.txt</code>?	The relative resolve appends: <code>docs\notes\week.txt\extra.txt</code>.<br>The absolute resolve replaces the original: <code>C:\temp\x.txt</code>.	week8 io
What are <code>Path.of(&quot;a&quot;, &quot;..&quot;, &quot;b&quot;, &quot;.&quot;, &quot;c&quot;).normalize()</code> and <code>docs/notes</code> relativized to <code>docs/code/A.java</code>, on Windows?	Normalize is <code>b\c</code>. It drops <code>.</code> and applies <code>..</code>.<br>Relativize is <code>..\code\A.java</code>, the path from the first location to the second.	week8 io
<code>notes.txt</code> contains <code>Ada loves Java</code>. The program trims, splits on whitespace, and writes <code>words=</code> plus the count. What prints?	<code>words=3</code>.<br><code>Files.readString</code> and <code>Files.writeString</code> throw the checked <code>IOException</code>.	week8 io
A <code>Bag</code> has <code>n = 7</code> and <code>transient t = 9</code>. After serialization and reading it back, the constructor ran only for the original <code>new</code>. What are <code>n</code>, <code>t</code>, and the constructor count?	<code>7 0 1</code>.<br><code>transient</code> is not saved and comes back as the default. Deserialization does not run the constructor. <code>static</code> fields are not one object's saved state.	week8 locale
What is <code>serialVersionUID</code> for?	It names the class shape.<br>Reading a stream whose id does not match the class throws <code>InvalidClassException</code>.	week8 locale
What does <code>NumberFormat.getCurrencyInstance(Locale.US).format(1.5)</code> print? What is the US short date for 21 Dec 2026?	<code>$1.50</code> and <code>12/21/26</code>.<br>The symbol, the separators, and the date order come from the locale.	week8 locale
For <code>Locale.FRENCH</code> and base name <code>messages</code>, what is the search order? <code>bye</code> is only in the base file. Which file supplies it?	Search <code>messages_fr</code>, then <code>messages</code>. A full locale searches language plus country before the language file.<br><code>bye</code> comes from <code>messages.properties</code>. A missing base bundle throws <code>MissingResourceException</code>.	week8 locale
Which directive makes a package visible to another module, and which directive reads another module?	<code>exports</code> makes the package visible.<br><code>requires</code> reads the other module. A call across modules needs both.	week8 modules
Who writes <code>provides ... with ...</code>, and who writes <code>uses</code>?	The provider module writes <code>provides Interface with Implementation</code>.<br>The consumer writes <code>uses Interface</code>. The consumer does not <code>require</code> the provider module by name.	week8 modules
What does <code>java -p out -m com.example.app/com.example.app.Main</code> print for the service in the Week 8 notes?	<code>hello</code>.<br><code>-p</code> is the module path. <code>-m</code> is the module and the main class. <code>ServiceLoader</code> finds the provider because it is on that path and the app <code>uses</code> the service.	week8 modules
A module <code>requires</code> another module, but the imported package is not exported. What does the compiler say?	The package is not visible.<br>The detail says the package is declared in that module, which does not export it. <code>requires</code> does not export packages.	week8 modules
What is the difference between <code>run</code> and <code>start</code>?	<code>run</code> executes the body on the current thread. It does not schedule a new thread.<br><code>start</code> schedules the thread. Calling <code>start</code> twice throws <code>IllegalThreadStateException</code>.	week8 threads
What do <code>Future.get</code>, <code>shutdown</code>, and <code>shutdownNow</code> do?	<code>get</code> blocks until the task finishes and returns its value. A task failure arrives as <code>ExecutionException</code>.<br><code>shutdown</code> rejects new tasks and lets current tasks finish. <code>shutdownNow</code> interrupts running tasks and returns the tasks that had not started.	week8 threads
Two threads each do <code>count = count + 1</code> a thousand times with no lock. What can the total be? What does <code>AtomicInteger</code> produce for the same loops?	The plain <code>int</code> total can be below 2000. Both threads can read the same value and write the same next number.<br><code>AtomicInteger.incrementAndGet</code>, or a <code>synchronized</code> increment, ends at <code>2000</code>.	week8 threads
Which thread state is <code>Thread.sleep</code>? Which state is waiting to enter a <code>synchronized</code> block?	<code>sleep</code> is <code>TIMED_WAITING</code>. Waiting for a monitor is <code>BLOCKED</code>.<br><code>NEW</code> is before <code>start</code>. <code>WAITING</code> is an untimed <code>wait</code> or <code>join</code>. <code>TERMINATED</code> is after the body finishes.	week8 threads
How does <code>Callable</code> differ from <code>Runnable</code>? How do you run one virtual thread per task?	<code>Runnable.run</code> returns void and cannot throw a checked exception. <code>Callable.call</code> returns a value and can throw <code>Exception</code>.<br>Use <code>Executors.newVirtualThreadPerTaskExecutor()</code>, or <code>Thread.ofVirtual().start</code>. Do not build a pool of virtual threads by hand.	week8 threads
Which annotations should you recognize, and what is a log call?	<code>@Override</code> checks an override. <code>@FunctionalInterface</code> checks one abstract method. <code>@Deprecated</code> marks an element to stop using. <code>@SuppressWarnings</code> silences a named warning.<br>A logger records a level and a message. <code>System.Logger</code> and <code>java.util.logging</code> are the names to recognize.	week8 locale
<code>Files.lines</code> and <code>Files.walk</code> return streams. What must you do with them?	Close them.<br>A try-with-resources is the usual way. They throw the checked <code>IOException</code>.	week8 io
