Q1. What is the output?

public class Q1 {
    static int count;
    static boolean ready;
    public static void main(String[] args) {
        System.out.print(count);
        System.out.print(ready);
    }
}

答案：A。 A missing int field is 0. A missing boolean field is false. Printing them produces 0false with no space.

Q2. Which of the following compile? (Choose all that apply.)

byte a = 127;
byte b = 128;
long c = 3_000_000_000;
long d = 3_000_000_000L;
float e = 1.0;
char f = 65;
int g = 018;
int h = 011;

答案：A、D、F、H。 127 fits in a byte. 128 does not. 3_000_000_000 is an int literal that is too big; the L makes it a long. 1.0 is a double and does not fit in a float variable without a cast or an f. 65 fits in a char. 018 is illegal octal. 011 is octal for 9, and it compiles.

Q3. What is the result?

        System.out.println(local);

}

答案：C。 local is a local variable. Locals have no default. Reading it before assignment does not compile. The same name as a field would have printed 0.

Q4. Which lines compile? (Choose all that apply.)

var a = 10;
var b = null;
var c = (String) null;
var d = {1, 2};
var e = new int[] {1, 2};

答案：A、C、E。 var needs an initializer with a clear type. null alone has no type. A cast supplies one. {1, 2} is not a standalone expression. new int[] {1, 2} is. var declares one variable, so the comma form does not compile.
