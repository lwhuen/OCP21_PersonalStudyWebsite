What four rules make a legal override?	The signature matches.<br>The return type is the same or a subtype (covariant).<br>Access is the same or wider.<br>A checked exception is the same, narrower, or absent.	week4 override
How do <code>static</code>, <code>private</code>, and <code>final</code> methods interact with overriding? What does <code>@Override</code> check?	A <code>static</code> method is hidden, not overridden. A <code>private</code> method is not visible, so the child method is new. A <code>final</code> method cannot be redeclared.<br><code>@Override</code> fails unless a real override exists.	week4 override
<code>Animal dog = new Dog()</code>. <code>Animal.kind</code> is <code>animal</code>, <code>Dog.kind</code> is <code>dog</code>, and <code>Dog.speak</code> returns <code>woof</code>. What is <code>dog.kind + dog.speak()</code>?	<code>animal woof</code>.<br>The reference type selects the field. The object type selects the override. A <code>Cat</code> through an <code>Animal</code> reference prints <code>animal meow</code>.	week4 types
Same objects. What is <code>((Dog) dog).kind</code>?	<code>dog</code>.<br>The cast changes which field is read. The object really is a <code>Dog</code>, so the cast succeeds.	week4 types
<code>fetch</code> exists only on <code>Dog</code>. Does <code>Animal a = new Dog(); a.fetch();</code> compile?	No. The compiler looks at the reference type <code>Animal</code>.<br><code>((Dog) a).fetch()</code> compiles.	week4 types
What is <code>null instanceof Dog</code>? What does <code>(Dog) new Animal()</code> do?	<code>instanceof</code> on <code>null</code> is <code>false</code>. It does not throw.<br>The cast compiles and throws <code>ClassCastException</code>, because the object is not a <code>Dog</code>.	week4 types
<code>Animal.speak</code> and <code>Dog.speak</code> are both <code>static</code> and return <code>animal</code> and <code>dog</code>. <code>Animal a = new Dog()</code>. What is <code>a.speak()</code>?	<code>animal</code>.<br>A static method is hidden. The reference type selects it.	week4 override
<code>Animal.call</code> returns the private <code>speak</code>, which returns <code>animal</code>. <code>Dog</code> declares a public <code>speak</code> that returns <code>dog</code>. What is <code>new Dog().call()</code>?	<code>animal</code>.<br>A private method is not overridden. <code>call</code> stays bound to <code>Animal</code>'s private method.	week4 override
Does <code>@Override void speak(int n)</code> compile when the parent method is <code>void speak()</code>?	No. The signature does not match, so this is an overload, not an override.<br>Without <code>@Override</code> it would compile, and it still would not override.	week4 override
The parent method is <code>public void speak()</code>. The child declares <code>void speak()</code>. Does it compile?	No. An override cannot narrow access.<br><code>public</code> may become <code>public</code> only, not package-private.	week4 override
The parent <code>speak</code> throws <code>IOException</code>. The child <code>speak</code> throws <code>Exception</code>. Does it compile?	No. <code>Exception</code> is a broader checked exception.<br>The child may throw <code>IOException</code>, a subtype such as <code>FileNotFoundException</code>, or no checked exception.	week4 override
Parent <code>create</code> returns <code>Animal</code>. Child <code>create</code> returns <code>Dog</code>. Does that override compile?	Yes. <code>Dog</code> is a subtype of <code>Animal</code>, so the return is covariant.	week4 override
What is <code>x.equals(null)</code> for a normal <code>equals</code>? If <code>a.equals(b)</code> is true, what must be true of the hash codes?	<code>equals(null)</code> is <code>false</code>.<br>The hash codes must match. Matching hash codes do not imply <code>equals</code>.	week4 equals
Two <code>Bad(1)</code> objects override <code>equals</code> and not <code>hashCode</code>. Two <code>Good(1)</code> objects use <code>n</code> as the hash code. What are the <code>HashSet</code> sizes?	<code>2</code> and <code>1</code>.<br>The broken pair can both sit in the set. The fixed pair collapses to one element.	week4 equals
<code>DogPet</code> inherits <code>Pet.speak</code>. <code>CatPet</code> overrides it with <code>meow</code>. What is <code>dog.speak()</code>, <code>cat.speak()</code>, and <code>Pet.home()</code>?	<code>pet meow home</code>.<br>A default method is inherited. An interface static method is called on the interface. <code>DogPet.home()</code> does not compile.	week4 equals
Two interfaces declare the same default <code>move</code>. The class implements both and does not override <code>move</code>. Does it compile?	No. The class must override <code>move</code>.<br>One inherited default is fine. Two conflicting defaults are not.	week4 equals
Does <code>new Season(&quot;warm&quot;)</code> compile? What are <code>Season.WINTER.feel()</code> and <code>Season.SUMMER.ordinal()</code>?	<code>new Season</code> does not compile. The constructor is private.<br><code>feel</code> is <code>cold</code>. <code>SUMMER</code> is the second constant, so its ordinal is <code>1</code>.	week4 equals
A compact constructor sets <code>cents</code> to <code>0</code> when it is negative. What is <code>new Coin(-5).cents()</code>? Does <code>getCents()</code> exist?	<code>0</code>.<br>The compact constructor assigns the parameter. The field is stored after that. The accessor is <code>cents()</code>, not <code>getCents()</code>.	week4 patterns
A sealed <code>Shape</code> permits only <code>Circle</code> and <code>Rect</code>. The switch has those two cases and no <code>default</code>. Does it compile? What does a <code>Circle(3)</code> describe as?	It compiles. The permits list makes the switch exhaustive.<br>The description is <code>circle3</code>.	week4 patterns
Does this compile?<pre>case CharSequence c -&gt; 1;<br>case String s -&gt; 2;</pre>	No. <code>case String</code> is dominated by the earlier <code>CharSequence</code> case.<br>Put the more specific pattern first.	week4 patterns
<code>case Point(int x, int y) when x &gt; 0 -&gt; &quot;right&quot;</code>, then a plain <code>Point</code> case <code>&quot;other&quot;</code>. What are <code>Point(2, 1)</code> and <code>Point(-1, 4)</code>?	<code>right</code> and <code>other</code>.<br><code>when</code> guards the first pattern. A negative <code>x</code> falls through to the second pattern.	week4 patterns
A switch has <code>case null -&gt; &quot;null&quot;</code>. What does a null selector do? What if that case is missing?	It selects <code>null</code>.<br>Without <code>case null</code>, a null selector throws <code>NullPointerException</code>.	week4 patterns
What can a static nested class see, and how do you create one?	It has no hidden outer instance. It can use the outer class's private static members.<br>Create it with <code>new Outer.Nested()</code>.	week4 nested
What can an inner class see? Can it read a private field of the outer class?	Each inner object has a hidden outer object. It can read the outer class's private instance members.<br><code>Outer.this</code> is that outer object. On Java 21 an inner class may declare static members.	week4 nested
A local class reads local variable <code>n</code>, and the method then assigns <code>n</code> again. Does this compile?	No. A local or anonymous class may use a local variable only when it is final or effectively final.	week4 nested
<code>sealed interface Shape permits Box</code>, and <code>class Box implements Shape</code> with no <code>final</code>, <code>sealed</code>, or <code>non-sealed</code>. Does it compile?	No. A permitted class must say how the seal continues.<br>A record is implicitly <code>final</code>, so a record can implement the sealed type without writing <code>final</code>.	week4 patterns
